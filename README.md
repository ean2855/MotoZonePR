# MotoZone PR

MotoZone PR es un sitio web responsivo creado como parte de una tarea académica.

El sitio está dedicado al tema de motocicletas y fue desarrollado utilizando HTML, CSS y Bootstrap.

## Páginas del sitio

- Inicio
- Motocicletas
- Contacto
- Detalle Kawasaki Z900
- Detalle Kawasaki Z500

## Características

- Barra de navegación utilizando Bootstrap
- Diseño responsivo para dispositivos móviles y computadoras
- Imagen de fondo en la página principal
- Tarjetas de Bootstrap
- Botones de navegación
- Formulario de contacto
- Validación de formulario con Bootstrap
- Estilos personalizados con CSS

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Visual Studio Code
- GitHub
- GitHub Pages
